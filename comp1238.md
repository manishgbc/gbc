
# COMP1238 - Data Management Notes

## Week 1 - History of Writing

- Writing systems allow people to record and communicate information across time.
- Cuneiform is an ancient writing system associated with Mesopotamia.

## Week 2 - Bits and Bytes

- A bit is the smallest unit of digital information and represents 0 or 1.
- A byte consists of 8 bits and can represent 256 different values.

## Week 3 - Data Structure

- Data structures organize information so it can be stored and accessed efficiently.
- Different structures are useful for different types of data and operations.

## Week 4 - Data and Information

- Data consists of raw facts, while information is data organized to provide meaning.
- Consistent formats and accurate data help improve the quality of information.

## Week 5 - Databases

- A database stores organized data so it can be retrieved and managed.
- Tables contain rows (records) and columns (fields) in a relational database.
