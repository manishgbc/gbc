# COMP1238 - Data Management Notes

## Week 1 - History of Writing
- Cuneiform was an early writing system developed in Mesopotamia.
- Gutenberg's printing press used movable metal type.
- Serif fonts have decorative strokes; sans-serif fonts do not.

## Week 2 - Bits and Bytes
- A bit represents 0 or 1; a byte contains 8 bits.
- Binary uses base 2, decimal base 10, and hexadecimal base 16.
- RAM is volatile; SSDs and HDDs are non-volatile storage.

## Week 3 - Structure of Text
- Markdown uses simple symbols to format text and headings.
- HTML uses tags such as `<p>`, `<h1>`, and `<li>`.
- UTF-8 encodes Unicode characters using one to four bytes.

## Week 4 - Keyboards -and- Editors
- VS Code is a popular editor for writing and editing code.
- Ctrl + F searches for text; regex searches for patterns.
- GitHub Pages publishes websites from GitHub repositories.

## Week 5 - Command Line Interfaces
- `pwd` shows the current directory; `ls` lists files.
- `cd` changes directories; `mkdir` creates directories.
- SSH provides secure remote access to computers.
